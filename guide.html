1它到底是个啥

别被名字骗了——它不教你健身，它管两件事：今天练什么、今天练了没。

① 打开就知道今天该练哪几个动作、几组、几次，每个动作下面还写着要领。

② 练完一个动作点一下方块，全勾完就算完事，然后打卡。

③ 你俩各有一份计划（男女练的重点本来就不一样），但记录在同一个地方。

④ 所有动作、组数、要领都能改——它是个草稿本，不是圣旨。

它不是让你变成健身博主，是让你俩在「今天要不要练」这件事上，少吵一次架。

2每天就三步

  1. 打开 App，看「今天」上面写着今天练什么（推 / 拉 / 腿 / 有氧 / 休息……），还有完成度那个大圆环。
  2. 练完一组，点一个方块4 组就 4 个方块，点一下变蓝打勾。手机会轻轻震一下。
  3. 练完，底部点「打卡」选今天的感觉（很爽 / 一般 / 有点累），想写就写一句，然后「完成打卡」——会蹦出一张庆祝卡。
不用诚实到每一下都数清楚。练完三组点三下就行。这些记录是留给三个月后的你俩看的，不是交给教练检查的。

3底下那四个按钮

今天今天练什么、打勾、打卡
记录日历 + 统计，翻旧账用
我们你俩的对比、挑战、留言
我的改计划、改名字、开同步

点错了不要紧，随时切回来，数据不会丢。

4她那边多一个东西

女生版在「今天」页上方多一行小按钮：🌸 来例假了？点一下标这天。

  1. 点一下这天就被标成经期，页面会出现「经期第 1 天」。
  2. 需要的话点「轻松点」每个动作自动少一组（本来就 1 组的除外），备注里会记一句「经期，组数减一」，翻记录时能对得上。
  3. 不想要了点「标记结束」，或者去「我的 → 周期记录」里清除。
他那边只会看到一句「她这几天在经期，训练可以轻一点」，看不到具体日期和天数。她可以在「我的 → 周期记录」里一键关掉这个提示。

5你俩的玩法

这些都在「我们」那一页：

⚔️ 本周对决　这周谁完成的组数多，条形图直接摆出来，输的请喝水。下面还有历史战绩。

🎯 今日挑战　每天一条小任务（互相夸一句、帮对方数一组、拍张汗照……），两边各自打勾，都完成显示「双方达成」。

💬 留言板　想说的话写这儿，能选现成的打气话。

📸 打卡战报　打卡后生成一张竖图，长按保存，发微信或朋友圈。

🏅 成就　14 枚徽章，按记录自动算：第一次、十次、五十次、连续 3/7/30 天、双人并肩 7 天、500 组、完美一天……

6想改动作？随便改

计划是会变的：器械被占了、某个动作做着不舒服、今天只想练半小时——都能改。

只改今天：今天页 →「调整今天」→ 加减动作、改组数次数、换热身。

以后每周这天都这样：今天页 →「改成本周固定」。

换天（比如周三想休息）：我的 → 这一周怎么排 → 按住右边的 ☰ 拖到另一天，两天的安排直接互换。

加个新动作：「＋ 从动作库添加」，56 个健身房动作按部位分好；点名字先看要领，点 ⊕ 才加进去。

换顺序：动作列表右上角「排序」→ 按住卡片上下拖 → 完成。

改错了：「调整今天」最下面有「恢复默认」。

改「本周固定」不会改动历史记录。已经打完卡的日子是快照，改了计划它也不会变。

7翻旧账

「记录」那一页就是日历：

  • 实心圆点 = 这天打卡了
  • 绿色 = 休息日（休息也要打卡，也是记录）
  • 浅色 = 练了一半没打卡
  • 点任意一天，能翻回那天的动作和备注

连续天数断了别丧气——它只显示数字，不评价你。

8两台手机怎么是通的

开同步之后，你俩共用一个小仓库（建在 GitHub 上，私密的）。谁勾了组、谁写了留言，另一边几秒到半分钟内就能看到。

看状态：我的 → 双人同步。

✓ 刚刚同步　一切正常。

⚠️ 令牌无效　点「更新令牌」粘一串新的就行，记录不会丢（还在同一个仓库里）。换完把新的配对码发给对方。

🔍 同步自检　说不清哪里不对时点它，会告诉你令牌认不认、Gist 读不读得到。

连不上　手机网络问题。没网也能练，联网后会自动补上。

同步只做「合并」，不做「覆盖」。你俩各练各的，合到一起不会互相冲掉。留言两边都保留，挑战任意一边打勾就算完成。
令牌的三条铁律：只留一个、勾 repo + gist、选 No expiration 并且永远别删。删了它，两台手机都会断，得重新配一次（数据仍然在）。

9常见问题

没网能用吗？

能。App 会把自己缓存在手机上，飞机上、地下车库都能打开。联网后自动把新记录同步上去。

打卡打错了怎么办？

「今天」页最下面点「撤销」，再重新打卡就行。备注随时能改。

换手机会丢吗？

开了同步就不丢：新手机装好、粘同一个配对码，数据会拉下来。没开同步就用「我的 → 导出备份」。

进度照片会同步吗？

不会。照片体积太大，只存在你自己那台手机上，两边各拍各的。

她能看到我练了什么吗？

能看到——「我们」页有「你俩今天」的卡片，谁练到第几组都看得见。这是这个 App 的一半乐趣。

为什么有的日子没有动作？

那是休息日。休息日会让你勾「睡够觉、散步、拉伸」这类恢复项，勾完也能打卡，连续天数不会断。

能两个人以外的人用吗？

目前是给两个人设计的。以后想加人（比如朋友），跟我说，我改。
